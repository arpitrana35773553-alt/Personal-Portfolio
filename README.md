# Arpit Rana — Personal Portfolio

A responsive personal portfolio for Arpit Rana, a Computer Science Engineering student at Lovely Professional University, exploring the intersection of Artificial Intelligence and Cybersecurity.

## Highlights

- Premium, dark command-center-inspired visual design
- Responsive layout for desktop, tablet, and mobile
- Scroll reveals, staggered card animations, and reading-progress indicator
- Project showcase, learning-status skill matrix, career roadmap, and developer dashboard
- Functional contact form powered by Formspree

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Formspree

## Run locally

Open `index.html` in a browser, or serve the folder with a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

This repository is configured for GitHub Pages. In the repository settings, choose **Pages → Deploy from a branch → main → /(root)**.

## Contact

The contact form sends submissions through Formspree. Update the endpoint in `.html` if the Formspree form ID changes.
